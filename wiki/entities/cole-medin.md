# Cole Medin

## What it is

YouTube channel **Cole Medin** — an AI-coding / agentic-engineering creator and founder of **Dynamous** (`dynamous.ai`), whose *Agentic Coding Course* ("learn how to build reliable and repeatable systems for AI coding") is now fully released. His GitHub handle is **`coleam00`**. Enters this vault via [[youtube-digest-apify-2026-07-02]].

## Why it matters for this wiki

Cole's entry video is a **standards event directly about the vault's own architecture**: he breaks down **Google's [[open-knowledge-format]] (OKF)** — an open markdown standard that formalizes [[andrej-karpathy]]'s LLM-wiki pattern ([[karpathy-llm-wiki]]) into a cross-vendor spec. For a vault that *is* a Karpathy LLM wiki, this is the most architecturally relevant creator coverage since the pattern was commercially shipped ([[knowledge-layer]]). He is positioned as an **open-source-first practitioner** — his response to the standard is to publish a clonable OKF bundle, not sell a product.

## Key claims (from [[youtube-digest-apify-2026-07-02]] #2)

*Finally, an Open Standard for the Karpathy LLM Wiki is HERE* (15.6K views, 2026-07-02, 19:37):

- **Google shipped the Open Knowledge Format (OKF)** — *"an open standard that formalizes Andrej Karpathy's LLM wiki pattern into plain markdown any AI can read with zero integration. No plugin, RAG pipeline, or vector DB. You point your agent at a folder and ask it anything as long as it knows OKF."* → [[open-knowledge-format]]
- **The missing piece was never search — it was a shared format.** *"You already have a personal agent and search that works well... So why is it still basically impossible to hand your knowledge to someone else's AI and have it just work? The answer is we never agreed on a format — and that's exactly what Google has now solved."*
- **Ships an open-source OKF bundle** (`github.com/coleam00/cole-medi...`) — *"clone this and point your AI at it"* — so an agent can immediately search his YouTube content. A concrete, portable demonstration of the standard.
- **The Dynamous Agentic Coding Course is now fully released** (`dynamous.ai`) — repeatable systems for AI coding; the community/course behind his content.
- Sponsor: **PostHog** (product analytics / session replay / feature flags).
