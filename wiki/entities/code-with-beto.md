# Code with Beto

## What it is
Person (Beto Moedano) + YouTube channel **Code with Beto**. Audience: React Native + Claude Code developers. Runs Pro membership at `cwb.sh` with private skills + production codebases.

## Why it matters for this wiki
His Claude Skills tutorial (#6) is the **best practitioner-grade walkthrough** of skill design in this digest. He demonstrates the Skill Creator skill (Anthropic), shows real $100 MRR app (AI Tattoo App), and gives the canonical best practices: be concise, set degrees of freedom, test different models. Useful reference whenever the user is *writing* skills, not just installing them.

## Key claims (from video #6 *How to Create Good Agent Skills*)

- **Don't write skills manually** — use the Skill Creator skill from Anthropic
- **Best practices**:
  1. Be concise (don't blow your context window)
  2. Set degrees of freedom (constrain skill behavior explicitly)
  3. Test different models (skill behavior varies)
- **References folder pattern** — supplemental material loaded only when needed (this vault uses this for `references/` and `.templates/`)
- **Marketplace setup** — distributing skills to teams via marketplaces
