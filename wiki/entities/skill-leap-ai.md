# Skill Leap AI

## What it is

YouTube channel **Skill Leap AI** — an AI-education / how-to channel positioned for **beginners and non-technical creators**. Its content teaches practical AI-tool workflows in long-form, tutorial format. Enters the vault via [[youtube-digest-apify-2026-07-05]] with an 18-minute *Ultimate Guide To Claude Skills*. (Sponsor read links to a HubSpot "Guide to Claude Skills" — `clickhubspot.com/1bo6`.)

## Why it matters for this wiki

It fills the **beginner build-from-scratch** rung of the [[claude-skills]] curation ladder — below [[chase-ai]]'s Skill Creator walkthrough and alongside [[tristen-obrien]]'s sub-7-min explainer, but longer and more comprehensive (18:03). Two things make it worth tracking:

1. **[[skill-creator]] as the non-technical on-ramp** — the guide walks building a skill *from scratch* with Anthropic's meta-skill, framing it as the tool beginners should reach for rather than hand-writing markdown.
2. **Skill-safety / provenance framing** — the second explicit consumer-facing "internet skills can be risky, build your own, read the instructions" voice in the vault (after [[tristen-obrien]]), a growing recurring sub-theme of [[claude-skills]] as the marketplace fills with unvetted skills.

## Key claims (from [[youtube-digest-apify-2026-07-05]] #3)

*Ultimate Guide To Claude Skills* (29.5K views, 2026-06-29, 18:03):

- **The beginner arc** — *"what Claude skills are, where to find them, how to turn them on, and how to build a skill from scratch with the Claude skill creator."*
- **Named example skills** (mapped to everyday creator jobs):
  - a **writing-style skill**
  - a **deep-research auditor**
  - a **CSV dashboard builder**
  - a **content engine**
  - an **on-brand presentation maker**
  - → jobs: YouTube scripts, PDF reports, dashboards, blog posts, LinkedIn posts, slides.
- **Skill safety** — *"some Claude skills from the internet can be risky, so I show why I like building my own skills and checking the skill instructions before using them."* Prefers home-built skills + reading instructions before running third-party ones.
- Framed explicitly as *"a simple guide to Claude skills for beginners."*
