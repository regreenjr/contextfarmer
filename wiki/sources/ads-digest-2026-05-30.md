# FB Ads Digest — 2026-05-30

Fifteenth batch from the [[competitor-ads-farm]]. **8 new ads, 205 dedup-skipped** out of 213 fetched at a 1-day gap from batch 14 (2026-05-29). Apify `facebook-ads-library-scraper` actor.

## TL;DR

- **The batch-14 GENUINE three-wedge Hims surge does NOT sustain — [[hims]] collapses to a single placeholder.** Batch 14 ran the first non-compression three-wedge surge (4 ads: Wegovy + Sex Rx + Hair Hybrids ×2, all verbatim static copy). Batch 15, at a clean 1-day gap, ships just **1 Hims ad — a `{{product.brand}}` placeholder** (ID `1700002341326214`, started 2026-05-21). All three verbatim wedges go silent. **This RESOLVES the batch-14 open question** — the three-wedge surge was a **coincidental single-batch triple re-surface, not the start of a sustained surge.** The classic Hims surge→trough alternating cadence holds again (batch 14 surge → batch 15 trough), the same shape as batch 8→9, batch 5→6, etc.
- **Broad-thin signal batch — 3 tracked brands each ship exactly 1 ad** ([[hims]] + [[ro]] + [[openai]], all at the 1.0/day floor). This is the inverse of batch 14's Hims-concentrated surge (4 Hims ads, all other brands at 0). The **multi-brand trough is LIFTING** — both Ro and OpenAI return after their batch-14 silences. No single brand dominates batch 15.
- **[[ro]] returns from its 2-batch trough (13+14) with 1 placeholder — Run 4.** ID `3350581395113505`, started 2026-05-18, body `{{product.brand}}`. Well within Ro's irregular-burst cadence (Run 1 batches 1-2 / Run 2 batches 7-9 / Run 3 batch 12 / **Run 4 batch 15**, separated by 1-4-batch troughs). Cumulative **10 Ro ads across 15 batches, ALL placeholder-only.**
- **[[openai]] Cluster 4 (2026-05-22) reaches 2 ads — strengthens the "Cluster 4 opening" reading.** A 2nd carousel placeholder in the 2026-05-22 launch window (ID `965071979490390`, `{{product.name}}` / `{{product.brand}}`) after batch 13's first 2026-05-22 ad (ID `1351994566743163`) and batch-14 silence in between. Two ads in the same new launch window tips the diagnosis from the batch-13 "possible irregular catalog re-surface at 1 ad" toward **a genuine Cluster 4**. Cluster 4 looks like a **catalog-expansion cluster** (placeholder, like Clusters 1+2), not a retention-narrative cluster (Cluster 3). Cluster 3 (2026-05-15) remains **stalled at 3 ads / 1 with copy** (16 days post-launch). Cumulative **47 OpenAI ads, still 1 with copy.**
- **Real-signal rate drops to 37.5% (3 of 8)** from batch 14's 80% farm high — back near the farm mean (~37%). Batch 14's clean ratio reflected a thin 5-ad batch with 1 noise ad; batch 15's 8 ads draw 5 noise.
- **Per-day total recovers to 8.0/day but is noise-inflated.** 8 new / 1-day gap = 8.0 ads/day (back in the 8-9 baseline band) — but **5 of 8 are noise.** Signal-only is **3.0/day across 3 brands** (Hims 1.0 + Ro 1.0 + OpenAI 1.0). Batch 14's "recovery" to 5.0/day was a Hims surge; batch 15's recovery is a noise draw masking a balanced signal floor.
- **5 noise ads — 4 "Ro"-substring + 1 "Eden".** Both long-form **Cholesterol confession narratives return AGAIN shipping full copy** (Cholesterol Relief Community + Cholesterol Support Group — the latter with a **NEW** Tamika/probate-paralegal/mother's-medication-list narrative, distinct from its batch-8 ICU-nurse-statins narrative — the page A/B-tests multiple confession narratives). + 2 NEW "Ro"-substring noise pages (**Brown Beatrice Cathrin** AI-trend-filter spam; **Chronos Body, Health & Wellness** placeholder). + **Aelfric Eden EU** (fashion, "Eden" substring — a regional-page variant of the already-counted Aelfric Eden).
- **[[anthropic]] 4th consecutive silence (12+13+14+15)** — still within the slow-cluster window (next 2026-05-11-cluster ad expected ~2026-06-08 if the 14-day cadence holds; ≥5-silent-batch Anthropic threshold ⇒ silence through ~batch 16-17 to claim a stall). **[[eden]] (TryEden) 2nd consecutive silence (14+15)** after the batch-13 first signal — cadence still unknown. **Henry Meds / Hampton / DealMachine** — 15th consecutive batch no signal.
