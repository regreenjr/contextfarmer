# Agent Ownership

## What it is

[[nate-b-jones]]' **32nd named framework** (*You Can't Run AI Agents Without This*, 18.6K views, 2026-06-21, 14:20) in [[youtube-digest-apify-2026-06-24]]. The thesis: **agent ownership is the skill most teams skip in 2026.**

> *"Once an agent reads real files and does real work, somebody has to own it, and most people cannot say who."*

## The framing claim

> *"The common story is that agents are confusing because nobody agrees on the definition. The real question is who owns the work once the agent starts doing it."*

The reframe (chapter 01:35, *From assistant to agent*): **a working agent stops being a tool and becomes your responsibility.** A chat assistant you invoke is disposable; an agent that reads real files and acts on real work is a standing system someone must maintain — like a junior employee, not a calculator.

## The framework — care and feeding

The operating model (chapter 04:15, *Job, diet, boundaries, review loop*):

| Element | What it specifies |
|---|---|
| **Job** | What this agent is for — its scoped mandate |
| **Diet** | What context/files/data it's fed (and what it must *not* be fed) |
| **Boundaries** | What it's allowed to do — its action limits |
| **Review loop** | Who checks its output, how often, against what |

These four make an agent **owned** rather than orphaned. The artifacts (chapter 10:10, *The agent roster and owner card*):

- **Agent roster** — the list of every agent doing real work in the org
- **Owner card** — per agent: the named human accountable, plus its job/diet/boundaries/review loop

The closing claim (chapter 12:55): **maintenance is the 2026 skill.** *"The teams that name an owner for each one pull ahead of the teams collecting demos."* Where unowned team agents fail and who should catch them (chapter 07:10, product-team story-prep example).

- **The owner card is a ready-made deliverable** — a one-page-per-agent template (job / diet / boundaries / review loop / owner) is a clean consulting artifact, same family as his [[agent-metering]] four-question diagnostic.
- **"Who owns this agent?" is the diagnostic that surfaces shadow-agent risk** — most orgs running agents can't answer it; finding the unowned ones is immediate billable value.
