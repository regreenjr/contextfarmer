# Claude Skills

Reusable procedural-knowledge units in [[claude-code]]. Each skill is a markdown file (typically with frontmatter + body + optional scripts/templates) that Claude invokes when its trigger conditions match.

## Why it's a hot topic right now

[[youtube-digest-2026-05-03]] surfaced 4 of 7 videos covering Skills directly:
- [[nate-herk]]: *I Tried 100+ Claude Code Skills. These 6 Are The Best* (curation)
- [[greg-isenberg]]: *How AI agents & Claude skills work (Clearly Explained)* (mainstream explainer)
- Tech With Tim: *The Ultimate Claude Code Guide \| MCP, Skills & More* (umbrella tutorial)
- [[grace-leung]]: *Claude Design + Claude Skills: Automate Your Marketing* (vertical application)

The category has crossed from "early adopter only" to "explain-to-creators" mainstream awareness ([[greg-isenberg]]'s 266K views = 0.43x engagement, highest in the digest).

## Adjacent patterns

- **Skill marketplaces** are emerging — [[brad-bonanno]] mentioned a verified-skills marketplace waitlist on his channel
- **Skill curation videos** ("best of N skills") are an emerging format — implies there are now too many skills for users to evaluate solo
- **Vertical-specific skills** (marketing per [[grace-leung]]) are appearing — skills aren't just for devs anymore

## Why it matters for 3Ps

Skills are the canonical artifact for packaging consulting expertise:
- Methodology → skill
- Onboarding flow → skill
- Repeated client deliverable → skill
- Course content → skill bundle

The 3Ps consulting offering should ship skills, not just teach them.
